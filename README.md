# Daylight

A lightweight, browser-based to-do app inspired by Todoist. Daylight keeps your tasks in this browser using local storage, with Today, Upcoming, project, and priority views.

## Run it

Open `index.html` in a modern web browser. No build step or dependencies are required.

## Features

- Add tasks and set a date, project, and priority
- Mark tasks complete and review completed work
- Browse tasks by date, project, or priority
- Save task changes automatically in the current browser
- Responsive layout for desktop and mobile

Task data stays in the browser's local storage and is not synced between devices.
